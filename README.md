# Calculadora Simples
Calculadora desenvolvida com HTML, CSS e JavaScript para praticar conceitos de lógica de programação e manipulação do DOM.

## Funcionalidades
- Adição, subtração, multiplicação e divisão
- Números decimais
- Números negativos
- Botão C para limpar o visor
- Botão DEL para apagar o último caractere
- Validação de operadores
- Tratamento de erros
- Efeitos visuais e iluminação do display

## Tecnologias
- HTML
- CSS
- JavaScript

## Projeto
Projeto desenvolvido para prática e aprimoramento dos meus conhecimentos em desenvolvimento Front-end.
